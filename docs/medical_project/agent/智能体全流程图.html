七个编排步骤各做什么

  1. 输入校验：只检查、只记录。图不存在、问题为空这类问题写进错误列表，交给路由去判"无法处理"，节点本身不终止。
  2. 意图路由：六条规则自上而下先命中先生效；意图到工具计划的映射是一张数据表，不是散落的条件语句；每次决策落日志，日志就是将来评估语言模型路由的评测集。
  3. 执行工具：按计划逐个调用。每个工具先判"显式要求仿真？"再判"真实后端能加载？"再判"运行是否抛异常"。不可用时返回失败且数据为空，绝不偷偷换成仿真数据。任一工具失败只记错误，后面的照跑。参数依赖由这一步传递：定位需要检测的标签，检索词拼上检出标签的中文名，视觉问答把证据文本当参考，标注图拿到带框的发现列表。
  4. 汇总：把五个工具的输出合成一份结构化报告。定位只覆盖框和掩码，分数与来源保持检测器的，这样后面的溯源能分清"分数来自检测、位置来自热力图"。失败与仿真全部写进注意事项，报告生成器只能追加不能删。
  5. 报告生成：对结构化报告是只读的，写不了发现和证据。这是"语言模型不能编坐标、数值、来源"在架构上的保证。有 7B 医疗模型就用它，没有就走确定性模板；模板输出必须能通过安全校验。
  6. 安全校验：答案里每个数字回溯到检出分数、框坐标、证据文本或化验；每个病理名回溯到有依据的发现或证据；"肯定是""确诊为"直接标记；剂量表达按（数值，单位）是否落在被引原文里判豁免还是违规。
  7. 整理输出：拼来源清单（编号与正文一一对应）和标注图路径。补充设计里在这之后加一个分叉：安全标记非空的进医生复核队列，图在中断节点暂停，确认后放行。

四种意图对应的工具计划

意图触发工具顺序本机仿真实测
纯文本问答没有图检索跑通，检索到证据并带引用
影像分析有图，默认检测 → 视觉问答 → 检索跑通
位置查询有图 + 在哪 / 位置 / 定位 / 标出检测 → 定位 → 标注图跑通，框与掩码落盘
综合报告有图 + 报告 / 综合 / 全面 / 出一份检测 → 定位 → 视觉问答 → 检索 → 标注图跑通，3.9 秒，安全标记为空
无法处理无输入 / 图不存在 / 格式不支持无，短路到整理输出跑通，给出中文原因
